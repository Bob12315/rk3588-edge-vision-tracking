# RK3588 与机载硬件准备清单

## 待确认清单

- RK3588 板卡具体型号、内存容量、系统镜像与内核版本。
- NPU 驱动、RKNN Runtime/Toolkit 版本及已验证模型格式。
- 相机接口（MIPI/USB/网络）、传感器型号、分辨率、帧率和像素格式。
- 镜头焦距、视场角、曝光方式、白平衡和是否具备云台/电子防抖。
- PX4 或 ArduPilot 版本、飞控板、MAVLink 通道和伴随计算机链路。
- GPS/RTK、IMU、激光/双目/深度测距来源及时间同步方式。
- 供电电压、峰值功耗、散热、重量和安装振动约束。

## 首次上板记录

在目标板执行 `./scripts/check_rk3588.sh`，保存结果到实验记录，但不要提交序列号、网络配置或凭据。另行记录：

- 空闲、检测、检测+跟踪三个负载下的温度与功耗。
- 相机到达应用层的实际 FPS、曝光延迟和时间戳来源。
- NPU 推理前后 CPU 占用、内存峰值和热降频时间。
- 断开相机、飞控链路、GPS 和测距时的确定性降级行为。

## 接线前安全门槛

- 开发阶段先拆桨或使用独立测试架。
- MAVLink 输出默认关闭，通过显式配置才启用。
- 人工接管、急停和飞控 failsafe 的优先级高于伴随计算机。
- 模型异常、输入冻结、队列过期或进程崩溃一律进入 HOLD/飞控 failsafe。
