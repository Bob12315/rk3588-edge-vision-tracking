# 初始工程决策

## Python 负责原型编排

第一阶段使用 Python 3.10+ 固化接口、状态机与评估工具，原因是模型生态接入快、便于录制回放与实验。若 RK3588 端性能分析表明 Python 编排成为瓶颈，再将明确的热点模块迁移到 C++，不提前增加两套实现。

## JSON 作为第一版配置格式

核心模拟零第三方依赖，因此配置先使用标准库可读的 JSON。部署配置进入多环境和注释需求阶段后，可再评估 YAML/TOML 与模式校验。

## 模型产物不进入 Git

`.pt`、`.onnx`、`.rknn` 等大文件和数据集默认忽略。后续选定对象存储或 Git LFS 后，应为每个产物记录来源模型、转换命令、校准集哈希、工具链版本和文件校验和。

## 安全仲裁独立于模型

感知模块只输出观测；状态机提出高级动作；安全仲裁拥有最终覆盖权。定位异常时不盲目 RTL，而先 HOLD 并交由飞控既有 failsafe 与人工策略处理。
