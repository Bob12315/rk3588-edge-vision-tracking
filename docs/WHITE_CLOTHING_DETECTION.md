# 白衣人物识别（初始基线）

> 本页记录最初的固定 HSV 基线。当前网页和命令行已经升级为 12 色分类与
> Track ID 多帧稳定，见[衣服颜色识别与跟踪](CLOTHING_COLOR_TRACKING.md)。

## 结论

当前视频使用两级流程：

```text
YOLO-World + prompt "person"
             ↓
人物框上半身 ROI
             ↓
HSV 白色像素占比验证
             ↓
person wearing white clothes
```

不直接使用复合提示 `person wearing white clothes` 作为最终判定。该提示在代表帧中将多名红衣人物也识别为白衣，说明此 YOLO-World 权重能理解“人”，但颜色属性约束不稳定。

## 参数

| 参数 | 当前值 |
|---|---:|
| YOLO-World 模型 | `yolov8s-worldv2.pt` |
| 检测提示 | `person` |
| 人物检测阈值 | 0.05 |
| 上半身 ROI | 框内 x=18%–82%，y=18%–55% |
| 白色 HSV 条件 | saturation ≤ 60，value ≥ 145 |
| 白色像素占比 | ≥ 0.20 |
| 最小人物框高度 | 画面高度的 0.10 |

人物框左侧和右侧各缩进 18%，减少背景和手臂外侧区域；纵向只取头部以下到腰部附近，避免红衣人物的白袜影响判定。最小框高度门槛用于去掉远处亮色小目标误框。

## 本次结果

| 指标 | 结果 |
|---|---:|
| 成功处理 | 57 / 57 帧 |
| 白衣人物逐帧框 | 116 |
| 每帧白衣候选 | 1–3，平均 2.04 |
| 稳态推理 P50 | 90.42 ms |
| 稳态推理 P95 | 97.19 ms |
| 端到端 CPU 吞吐 | 9.96 FPS |

代表帧目视检查保留了左侧白/灰上衣人物和中间全身白衣人物，并排除了红色球衣队员。逐帧框数量不是独立人数；后续需要跟踪器分配跨帧 ID。

## 复现

```bash
make detect-white-person \
  VIDEO=/absolute/path/to/37abaa4512176295e7462a589a64674a.mp4
```

默认输出目录：`outputs/white_clothes_yolo_world_verified/`。

## 限制

- 当前没有人工逐帧真值，不能计算白衣识别的 precision、recall 或漏检率。
- 阴影、过曝、白平衡和浅灰/浅蓝衣服会改变 HSV 得分。
- 当前 ROI 假设人物基本站立；俯视、横躺或严重遮挡需要重新定义衣服区域。
- 换相机、场地或飞行高度后，必须用实际数据重新扫描阈值。
- 若比赛规则对“白衣”有严格定义，应训练颜色分类器替代固定 HSV 阈值。
